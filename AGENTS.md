# AcademyFind App UI/UX Standards & Agent Directives

## Core UI/UX Directive
Whenever creating, updating, styling, or editing ANY page, component, modal, or UI element in this application, you must consistently synthesize and apply the following design skills:

1. **`academyfind-ui-expert`**: The core design system of AcademyFind — warm amber palette, glassmorphism cards, 3D hover transforms, and authentic Indian EdTech credibility.
2. **`ui-ux-pro-max`**: Design intelligence database — styles, color palettes, typography pairings, UX guidelines, and pre-delivery checklists. Run `.agents/skills/ui-ux-pro-max/scripts/search.py` when exploring palettes, styles, or specific tech stacks.
3. **`frontend-design`**: Distinctive, craft-focused frontend engineering — avoiding generic "AI UI", adhering to DFII ≥ 8, formulating memorable design anchors, and maintaining aesthetic restraint.
4. **`antigravity-design-expert`**: Spatial UI and weightlessness — layered depth, smooth CSS 3D perspective transforms, subtle translucent backdrops, and staggered fluid transitions.

## Key Design Principles
- **No generic defaults**: Avoid flat, template-like cards or standard SaaS blue/purple gradients.
- **Craft & Motion**: Smooth transitions (`150ms-300ms ease-out`), subtle tactile feedback, and hover states with depth.
- **Accessibility & Performance**: Minimum 4.5:1 text contrast, accessible focus outlines, respect `prefers-reduced-motion`, and performant GPU-accelerated transforms (`transform`, `opacity`).
- **Icons**: Use SVG icons (e.g., Lucide React / Heroicons), never bare emojis for UI actions.
